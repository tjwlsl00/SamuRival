  <summary>ゆきむいて、ホイ！</summary>
  
  説明
  --
  いわゆる、「あちむいてほい」と「雪合戦」を組み合わせた遊びです。<br>
  相手の攻撃、回避経路を予測し、相手より先に勝利を取ること！

  ゲームの流れ 
  --
  プレイヤーは1P🔵、2P🔴の2人で、雪玉を投げて誰が先に相手を倒すかがこのゲームの勝利条件です。 
  
  ①最初にコインを用いて先攻を決める。<br>
  例）🔴(攻撃)→🔵(防御) 、🔵(攻撃)→🔴(防御) <br>
  <b>⚠️しかし、自分のターンで相手に雪玉を当てることができたら、攻撃権は維持されます。</b>
  
  ②キーボード操作 <br>
  攻撃/防御ともに同じ方向を共有し、各プレイヤーは相手の経路を予想する必要がある。 <br>
  
  <b>●方向選択(左右)</b><br>
  🔴:←、→<br>
  🔵: Z、C<br>
  
  <b>●アイテム操作</b><br>
  解放：🔵(Ｓ)、🔴(↑)　解放しない限り、一般的なターンになります。<br>
  選択：🔵(１番：Ｚ，２番：Ｘ，３番：Ｃ），🔴（１番：←，２番：↓，３番：→）<br>
  
  <b>●アイテム一覧</b><br>
  1番(攻撃アイテム)：雪玉のダメージを2倍増幅させる。<br>
  2番(防御アイテム)：相手の雪玉に当たった場合、そのダメージを相手にそのまま返す。<br>
  3番(防御アイテム)：自分が不利な時にターンを持ってくることができる。<br>
