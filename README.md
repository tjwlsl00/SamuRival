<details>
  <summary>雪むいて、ホイ！</summary>

❄️雪玉を投げて相手を先に倒す心理戦ゲームです。

## 🏆 勝利条件
相手の体力を先に消耗させて**KO**させれば勝利となります。

## 🔄 ゲームの流れ
1. **先攻決定:** ゲーム開始時にコイントスで攻撃の順番を決めます。
2. **攻撃権の維持:** 自分のターンに相手を当てると**攻撃権が維持**されます。
3. **ターン交代:** 攻撃に失敗すると相手に攻撃権が移ります。
   
## 🔥 スペシャルイベント: 逆襲チャンス
**「攻撃に失敗しても心配しないでください！」**
* 攻撃に失敗するたびに雪玉ポイントが溜まります。
* **雪玉を4回集めると** 攻撃失敗に関係なく即座に**逆攻撃チャンス**が与えられます！
* 危機的な状況を一気に覆す絶好のチャンスをお見逃しなく。
  
## 🎮 操作方法

攻撃と防御の際に相手の移動経路を予測して方向を選択してください。

| 機能 | 🔵 1P (青) | 🔴 2P (赤) |
| :--- | :--- | :--- |
| **方向選択** | `A`（左） / `D`（右） | `←`（左） / `→`（右） |
| **アイテム開放** | `W` | `↑` |
| **アイテム1** | `A`（攻撃2倍） | `←`（攻撃2倍） |
| **アイテム2** | `S`（ダメージ反射） | `↓`（ダメージ反射） |
| **アイテム3** | `D`（ターン取得） | `→`（ターン取得） |

## 🎁 アイテムシステム

アイテムを解放（`W`または`↑`）しなければ通常ターンで進行します。

| 番号 | 名前 | 効果 |
| :---: | :--- | :--- |
| **1** | **２倍ダメージ** | 雪玉のダメージを**2倍**増幅します。 |
| **2** | **跳ね返す** | 被撃時に受けたダメージを相手に**そのまま反射**します。 |
| **3** | **攻守交代** | 自分に不利な状況で強制的に**攻撃権を奪取**します。|

  <summary>トントン、コマンドビルダー(開発中)</summary>
  
  🔨家の建設に必要な材料を集め、相手より先に家を建てていくゲームです

## 🏆 勝利条件
時間内に相手より家を建てるもしくはその進行度が高い方のプレイヤーが勝ちます。

## 🔄 ゲームの流れ
1. **コマンド入力:** 一行のコマンド入力に成功たびに、家の建設進行度が上がります。
2. **速度と精密度の勝負:** コマンド入力に失敗するたびに、プレイヤーにはペナルティーが存在します。速度と精密度両立を満たせ！
3. **コンボシステム:** 一行のコマンド入力を5回成功すると、相手のコマンド入力を3秒停止させることができます。
 
## 🎮 操作方法
基本的な方向キーでゲームが行われます。

| 機能 | 🔵 1P (青) | 🔴 2P (赤) |
| :--- | :--- | :--- |
| **方向** | `W`（上） / `S`（下） / `A`（左） / `D`（右） | `↑`（上） / `↓`（下）/　`←`（左） / `→`（右） |
