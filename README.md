  <summary>雪むいて、ホイ！</summary>

## 🏆 勝利条件
雪玉を投げ、相手を先に倒したプレイヤーが勝ち！

## 🔄 ゲームの流れ
1. **先攻決定:** 最初にコイントスで攻撃の順番を決める。
2. **攻撃と防御の繰り返し:** 先攻から始め、攻撃と防御を繰り返す。相手を当てたら投げ続く、外したらターンは変わる。
3. **相手使用:** 攻撃と防御アイテムを適切に使い、逆転チャンス狙う。
   
## 🔥 攻撃チャンス
**攻撃に失敗するたびに雪玉ポイントが溜まる。**
* **ポイントが4ポイント溜まると** 攻撃失敗に関係なく即座に**逆攻撃チャンス**が与えられる！
  
## 🎮 操作方法
| 機能 | 🔵 1P (青) | 🔴 2P (赤) |
| :--- | :--- | :--- |
| **方向選択** | `A`（左） / `D`（右） | `←`（左） / `→`（右） |
| **アイテム開放** | `LCtrl` | `RCtrl` |
| **アイテム1** | `W` | `↑`|
| **アイテム2** | `A` | `←`|
| **アイテム3** | `S` | `↓`|
| **アイテム4** | `D` | `→`|


## 🎁 アイテムシステム
| 番号 | 名前 | 効果 |
| :---: | :--- | :--- |
| **1** | **２倍ダメージ(攻撃)** | 雪玉のダメージを**2倍**増幅します。 |
| **2** | **透視鏡(攻撃)** | 相手の選択結果を**透視**します。 |
| **3** | **跳ね返す(防御)** | 被撃時に受けたダメージを相手に**そのまま反射**します。 |
| **4** | **攻守交代(防御)** | 自分に不利な状況で強制的に**攻撃権を奪取**します。|

  <summary>トントンビルダー</summary>
 ## 🏆 勝利条件
相手より先に家を完成させたプレイヤーが勝ち！

## 🔄 ゲームの流れ
1. **コマンド入力:** 一行のコマンド入力に成功たびに、家の建設進行度が上がる。
2. **速度と精密度の勝負:** コマンド入力に失敗するたびに、プレイヤーにはペナルティーを受ける。速度と精密度両立を満たせ！
3. **コンボシステム:** 一行のコマンドを成功すると、Comboが溜まる！５Comboが溜まると、相手のコマンド入力を3秒停止させることができる。
 
## 🎮 操作方法
| 機能 | 🔵 1P (青) | 🔴 2P (赤) |

| **方向** | `W`（上） / `S`（下） / `A`（左） / `D`（右） | `↑`（上） / `↓`（下）/　`←`（左） / `→`（右） |

<details>
  <summary>アーチェリング</summary>

## 🏆 勝利条件
高いスコアを獲得したプレイヤーの勝ち！

## 🔄 ゲームの流れ
1. **順番決め:** 赤から始め、一回ずつストンを投げます。よりターゲットに近づいたプレイヤーからラウンドが始まる。
2. **ストンを投げる:** ターゲットに向かって、ストンを投げる。(ラウンドはプレイヤーごとに10回)
3. **スコア計算:**　10ラウンドが終わった後、スコアの高いプレイヤー勝ち。引き分けの場合また最初から。

## 🎮 操作方法
最初は方向、そして、強さを決定。

| 機能 | 🔵 1P (青) | 🔴 2P (赤) |
| :--- | :--- | :--- |
| **決定** | `W` | `↑` |

  <summary>アイスーモ</summary>
  
## 🏆 勝利条件
  相手を場外に押し落とせ、ラウンドを取れ！

## 🔄 ゲームの流れ
1. **BO3勝負:** 3ラウンドで先に２ラウンドを勝つこと。
2. **氷が解ける:** 20秒ごとに氷が解ける。
3. **ダッシュ:**　ダッシュボタンを長押し、ゲージを溜め込める。
