# ❄️ Snowball Fight (1vs1)

눈덩이를 던져 상대방을 먼저 쓰러뜨리는 2인용 심리전 게임입니다.

---

## 🏆 승리 조건
* 상대방의 체력을 먼저 소진시켜 **KO**시키면 승리합니다.

## 🔄 게임 흐름
1. **선공 결정:** 게임 시작 시 코인 토스로 공격 순서를 정합니다.
2. **공격권 유지:** 자신의 턴에 상대방을 맞히면 **공격권이 유지**됩니다.
3. **턴 교체:** 공격에 실패하면 상대방에게 공격권이 넘어갑니다.

---

## 🎮 조작법 (Controls)

공격과 방어 시 상대방의 이동 경로를 예측하여 방향을 선택하세요.

| 기능 | 🔵 1P (Blue) | 🔴 2P (Red) |
| :--- | :--- | :--- |
| **방향 선택** | `Z` (왼쪽) / `C` (오른쪽) | `←` (왼쪽) / `→` (오른쪽) |
| **아이템 개방** | `S` | `↑` |
| **아이템 1** | `Z` (공격 2배) | `←` (공격 2배) |
| **아이템 2** | `X` (데미지 반사) | `↓` (데미지 반사) |
| **아이템 3** | `C` (턴 가져오기) | `→` (턴 가져오기) |

---

## 🎁 아이템 시스템 (Items)

아이템을 개방(`S` 또는 `↑`)하지 않으면 일반 턴으로 진행됩니다.

| 번호 | 이름 | 효과 |
| :---: | :--- | :--- |
| **1** | **파워 스노우볼** | 눈덩이 데미지를 **2배** 증폭시킵니다. |
| **2** | **미러 실드** | 피격 시 받은 데미지를 상대에게 **그대로 반사**합니다. |
| **3** | **턴 스틸er** | 자신이 불리한 상황에서 강제로 **공격권을 탈취**합니다. |

  プレイヤーは1P🔵、2P🔴の2人で、雪玉を投げて誰が先に相手を倒すかがこのゲームの勝利条件です。 
  
  ①最初にコインを用いて先攻を決める。<br>
  例）🔴(攻撃)→🔵(防御) 、🔵(攻撃)→🔴(防御) <br>
  <b>⚠️しかし、自分のターンで相手に雪玉を当てることができたら、攻撃権は維持されます。</b>
  
  ②キーボード操作 <br>
  攻撃/防御ともに同じ方向を共有し、各プレイヤーは相手の経路を予想する必要がある。 <br>
  
  <b>●方向選択(左右)</b><br>
  🔴:←、→<br>
  🔵: Z、C<br>
  
  <b>●アイテム操作</b><br>
  解放：🔵(Ｓ)、🔴(↑)　解放しない限り、一般的なターンになります。<br>
  選択：🔵(１番：Ｚ，２番：Ｘ，３番：Ｃ），🔴（１番：←，２番：↓，３番：→）<br>
  
  <b>●アイテム一覧</b><br>
  1番(攻撃アイテム)：雪玉のダメージを2倍増幅させる。<br>
  2番(防御アイテム)：相手の雪玉に当たった場合、そのダメージを相手にそのまま返す。<br>
  3番(防御アイテム)：自分が不利な時にターンを持ってくることができる。<br>
