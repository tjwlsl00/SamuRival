雪玉を投げて相手を先に倒す心理戦ゲームです。

## 🏆 勝利条件
相手の体力を先に消耗させて**KO**させれば勝利となります。

## 🔄 ゲームの流れ
1. **先攻決定:** ゲーム開始時にコイントスで攻撃の順番を決めます。
2. **攻撃権の維持:** 自分のターンに相手を当てると**攻撃権が維持**されます。
3. **ターン交代:** 攻撃に失敗すると相手に攻撃権が移ります。

## 🎮 操作方法

攻撃と防御の際に相手の移動経路を予測して方向を選択してください。

| 機能 | 🔵 1P (青) | 🔴 2P (赤) |
| :--- | :--- | :--- |
| **方向選択** | `Z`（左） / `C`（右） | `←`（左） / `→`（右） |
| **アイテム開放** | `S` | `↑` |
| **アイテム1** | `Z`（攻撃2倍） | `←`（攻撃2倍） |
| **アイテム2** | `X`（ダメージ反射） | `↓`（ダメージ反射） |
| **アイテム3** | `C`（ターン取得） | `→`（ターン取得） |

## 🎁 アイテムシステム

アイテムを解放（`S`または`↑`）しなければ通常ターンで進行します。

| 番号 | 名前 | 効果 |
| :---: | :--- | :--- |
| **1** | **パワースノーボール** | 雪玉のダメージを**2倍**増幅します。 |
| **2** | **ミラーシールド** | 被撃時に受けたダメージを相手に**そのまま反射**します。 |
| **3** | **ターンスティールer** | 自分に不利な状況で強制的に**攻撃権を奪取**します。|
